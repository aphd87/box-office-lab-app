# Behind the Box Office Lab

Classroom dashboard for the Darden case "Behind the Box Office: Decoding Movie Magic" (UVA-S-0410).
Password-protected for the class. This repo holds only the app code: the film data lives in a private dataset and is
loaded at startup, so the app does nothing without the deployment's secrets.

Source of truth is the private repo `aphd87/Student-MBA-movies`; copy `app.py` here after changing it there.
